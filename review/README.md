# review/

Zone de relecture. Le workflow « 1 · Chercher des artistes » y dépose
`candidates.json`, un fichier de brouillons.

Rien de ce qui s'y trouve n'entre dans `artists.json` tant qu'un humain n'a pas
remplacé `A_VERIFIER` par un statut réel, renseigné la gravité et ajouté une
source de presse. C'est volontaire : Wikidata sait dire « condamné pour X », pas
si un appel a infirmé ni quand l'affaire est devenue publique.
